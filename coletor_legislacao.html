Coletor de Legislação do site do TRT-17

Alimenta a ferramenta 19 (Atos normativos) com a seção Legislação do portal · uso interno SGP

Por que existe

A seção Legislação do portal do TRT-17 tem os atos com o PDF oficial e cobre períodos que a compilação em PDF não tem (1997–2006). O portal só responde a consultas feitas de dentro dele (firewall AWS), então a coleta roda no seu navegador, na página do TRT, e baixa um arquivo JSON.

Uma vez só: instalar o favorito

  1. Mostre a barra de favoritos do Chrome (Ctrl+Shift+B).
  2. Arraste este botão para a barra: Coletar legislação TRT-17

Para atualizar

  1. Abra a seção Legislação do portal do TRT-17.
  2. Clique no favorito Coletar legislação TRT-17. Um quadro no canto mostra o progresso (pode levar de 30 minutos a algumas horas: o coletor anda devagar para respeitar o limite de pedidos do portal; a página precisa ficar aberta).
  3. No fim, o Chrome baixa legislacao_trt17_site.json. Se a coleta for interrompida, clique no favorito de novo: ela continua de onde parou.
  4. Copie o arquivo para a pasta Build e rode, junto com o PDF mais recente da compilação: 
    python build_atos_normativos.py "ATOS_NORMATIVOS_....pdf" --site legislacao_trt17_site.json
python deploy.py "Atos normativos: atualização" dados_atos_normativos.json
Se a coleta pausar: o portal limita o número de pedidos. O coletor espera e, se o limite continuar, para com o progresso salvo. Tente mais tarde: abra a página e clique no favorito — a coleta continua de onde parou.
